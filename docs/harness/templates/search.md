# 派工模板：搜尋／掃檔

> 用途：在 codebase 或檔案系統裡找東西。
> 建議派法：subagent_type=`Explore`，model=`haiku`（模式明確）或 `sonnet`（需要理解語意）。

```
【目標與動機】
找出：＜要找什麼，越具體越好：符號名／行為／設定值＞
因為：＜找到之後要拿來做什麼——這讓你能判斷邊界案例算不算＞

【範圍】
搜尋範圍：＜目錄／檔案類型；沒把握就寫「整個 repo」＞
不需要涵蓋：＜明確排除的範圍，例如測試檔、vendored 目錄＞
搜尋廣度：＜medium（找到即可）／very thorough（要窮盡所有出現點）＞

【驗收條件】
- 每個結果附 檔案:行號。
- 若一無所獲，回報你試過哪些關鍵字與路徑（證明找過，不是沒找）。
- ＜可選：預期大約 N 個結果；差太多要說明＞

【回報格式】
- 結果列表：`路徑:行號 — 一句話說明這裡是什麼`。
- 最後一段：搜尋覆蓋範圍與你不確定的地方。
- 全文不超過 30 行；超過就落檔到 docs/notes/search-＜主題＞.md
  （目錄不存在就建立），只回摘要。
- 用詞：只用日常常見的詞，不自創名詞或標籤；術語第一次出現用一句話解釋；
  同一概念全文用同一種說法（完整規則見 CLAUDE.md 溝通方式第 7 條）。
```
