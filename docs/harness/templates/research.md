# 派工模板：研究／查資料

> 用途：查外部文件、比較方案、搞懂某個技術問題。
> 建議派法：subagent_type=`general-purpose`，model=`sonnet`；需要權衡判斷的選型研究用 `opus`。

```
【目標與動機】
研究問題：＜一句話的問題，最好能用「是/否/選項N」回答＞
因為：＜這個答案會決定什麼——讓研究者知道哪些細節重要＞

【範圍】
- 必須回答：＜子問題列表＞
- 不需要：＜例如「不需要完整教學，只要適用性結論」＞
- 時間框：來源以 ＜年份＞ 之後為準，過舊的標明。

【驗收條件】
- 每個結論附來源（URL 或檔案路徑）。
- 區分「來源明說的」與「你推論的」，推論要標明。
- 查不到就寫查不到＋試過的關鍵字，禁止編造。

【回報格式】
- 報告落檔到 docs/notes/＜主題-日期＞.md（目錄不存在就建立）。
- 回報只給：路徑 + 每個必答子問題的一行結論 + 信心等級（高/中/低）。
- 用詞：只用日常常見的詞，不自創名詞或標籤；術語第一次出現用一句話解釋；
  同一概念全文用同一種說法（完整規則見 CLAUDE.md 溝通方式第 4 條）。
```
